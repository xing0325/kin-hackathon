# KIN Fluid Glass Web

Interactive landing-page prototype for the Builder Agent Network.

```bash
npm install
npm test
npm run dev
```

The full-screen Canvas 2D scene runs a deterministic lightweight agent system:

- separation, alignment and cohesion;
- affinity-weighted relationship reinforcement;
- world-line trails;
- relationship field distortion;
- agent birth through pointer interaction;
- scene events driven by page scroll.

The visual system deliberately avoids a literal radar, green hacker UI, and a static node-link graph.
