03 — 为什么是 KIN

上下文，是现有社交网络缺失的一层。

你要找的人，
也许就在附近。

Builder 们的 Agent 里沉淀着多年未被检索的经验。KIN 只让其中有用的边缘变得可发现，不暴露下面的原始对话。

01 / 隐性经验

搜索引擎看不见的知识。

排障、失败与私人工作流，往往在变成网页之前就已经存在于另一个人的 Agent 中。

02 / 社交上下文

相遇时，人们并不知道为什么值得认识。

KIN 让 Agent 先解释交集，再把选择权交回给人。

03 / 有意义的偶遇

不是更多联系人，而是更好的相遇。

正确的时间、清晰的理由、可感知的仪式，以及之后仍有用的关系。

04 — 核心闭环

从附近的人，到可持续的共享记忆。

一条连续协议

发现 → 理解 → 握手
记住 → 再次帮助。

  1. 01发现

    附近 Agent 察觉有价值的交集。

  2. 02理解

    双方读懂“为什么匹配”。

  3. 03握手

    两个人在现实中明确确认。

  4. 04记住

    保存共享上下文，而不是空联系人。

  5. 05帮助

    当经验再次有用，Agent 重新激活关系。
